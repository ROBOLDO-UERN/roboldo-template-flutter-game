# 🎮 [TEMPLATE] Jogo Educativo / App Flutter — Lojinha do Roboldo

Template oficial da organização **[ROBOLDO-UERN](https://github.com/ROBOLDO-UERN)** para criação de novos **jogos educativos, dinâmicas inclusivas (TEA/CAA) e aplicativos em Flutter** integrados à **Lojinha do Roboldo**.

## 🚀 Como usar este Template
1. Clique em **"Use this template"** -> **"Create a new repository"** na organização `ROBOLDO-UERN`.
2. Preencha o manifesto `roboldo-app.json` com os metadados do seu jogo/aplicativo para publicação no catálogo da **Lojinha do Roboldo**.
3. O pipeline de **CI/CD** (`reusable-flutter-ci.yml`) valida automaticamente o código Dart/Flutter a cada commit/PR.
4. Acompanhe sua tarefa no **[Painel Geral da Organização (Project #6)](https://github.com/orgs/ROBOLDO-UERN/projects/6)** e no **[Project da Zona 5](https://github.com/orgs/ROBOLDO-UERN/projects/5)**.
